# Cyber Jungle

## 프로젝트 소개

Cyber Jungle은 교육 과정 구성원이 같은 가상 캠퍼스에 접속해 실시간으로 만나고, 대화하고, 파티를 모집할 수 있는 2D 커뮤니티 서비스입니다.

## 서비스 화면

### 로비

메인 진입 공간으로, 사용자가 처음 접속한 뒤 다른 공간으로 이동하기 전에 머무르는 공용 허브입니다.

![로비 화면](./docs/images/lobby.png)

### 농구 코트

사용자가 이동해서 진입할 수 있는 세부 공간 중 하나로, 로비와 구분된 별도 area 화면입니다.

![농구 코트 화면](./docs/images/basketball_court.png)

### 카페테리아

대화와 파티 모집이 가능한 공간으로, 다른 테마의 area가 어떻게 구성되는지 보여주는 예시 화면입니다.

![카페테리아 화면](./docs/images/cafeteria.png)

### 강의실

가상 캠퍼스 내 학습 공간 콘셉트를 반영한 area로, 사용자가 공간 단위로 이동하며 상호작용할 수 있음을 보여줍니다.

![강의실 화면](./docs/images/classroom.png)

## 기획 의도
- 정글 내에서 타 교육장, 타 교육과정 사람들과의 소통 부재를 경험
- 가볍게 즐길 수 있는 메타버스 환경에서 소통하는 경험을 통해 커뮤니케이션 활성화를 도모

## 주요 기능

- 사용자 정보를 입력하여 바로 입장할 수 있습니다.
- 같은 공간의 사용자 위치와 움직임이 실시간으로 동기화됩니다.
- 채팅을 통해 다른 사용자와 대화할 수 있습니다.
- 로비를 제외한 공간에서 파티를 만들고, 정해진 인원만큼 참여할 수 있습니다.
- 같은 area에 있는 사용자끼리 음성 연결을 시도할 수 있습니다.

## 담당 역할

이 프로젝트에서 저는 음성 커뮤니케이션 기능을 담당했습니다. 목표는 같은 장소(area)에 있는 사용자들끼리만 서로 음성으로 소통할 수 있도록 만들어, 공간 기반 커뮤니티 경험을 더 자연스럽게 만드는 것이었습니다.

- `M` 키를 눌러 마이크 입력을 켜고 끌 수 있도록 구성했습니다.
- `V` 키를 눌러 다른 사용자의 음성을 수신할지 여부를 제어할 수 있도록 구성했습니다.
- 같은 장소에 있는 사용자들 사이에서만 음성 연결을 시도하는 흐름을 구현해, 불필요한 전체 연결이 발생하지 않도록 설계했습니다.

이 기능을 통해 사용자가 단순히 채팅만 하는 것이 아니라, 같은 공간에 모인 사람들과 더 빠르고 자연스럽게 소통할 수 있는 환경을 만들고자 했습니다.

구현 과정에서 가장 어려웠던 부분은 마이크 입력을 서버를 거쳐 다른 사용자에게 어떻게 전달할 것인지 이해하는 일이었습니다. 브라우저에서 제공하는 마이크 접근 기능을 이용해 로컬 환경에서 입력을 다루는 것 자체는 비교적 수월했지만, 원격 사용자 간 음성 데이터를 안정적으로 주고받는 부분은 끝까지 완성하지 못했습니다.

이번 작업을 통해 브라우저 음성 처리와 실시간 통신의 기본 흐름은 경험할 수 있었지만, 실제 서비스 수준으로 구현하려면 음성 데이터가 어떤 방식으로 공유되고 연결되는지에 대한 이해가 더 필요하다는 점을 느꼈습니다. 앞으로는 WebRTC 기반 음성 전송 구조와 시그널링 흐름을 더 깊이 학습해, 원격 환경에서도 안정적으로 동작하는 음성 기능을 완성하는 것을 다음 과제로 보고 있습니다.

## 기존 버전 대비 개선점

- 단일 맵 기반 구조에서 로비와 세부 공간으로 이동하는 구조로 확장했습니다.
- 단순 채팅 중심 서비스에서 파티 모집과 참여 중심 서비스로 발전시켰습니다.
